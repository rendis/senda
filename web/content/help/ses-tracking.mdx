# SES tracking

Senda can help you set up email tracking for an SES adapter.

The important thing to understand is that tracking is **adapter-scoped**, not account-scoped.

## What gets created

When tracking is provisioned, Senda works with the adapter's SES setup to create:

- a Configuration Set
- an SNS Topic
- an HTTPS subscription back to Senda

## What is reused

If you retry provisioning for the **same adapter**, Senda reuses the persisted provisioning state for that adapter.

That means retries are safe and do not need to rebuild the whole setup from scratch.

## What is not reused

If you create another adapter, even if it points to the same AWS account or the same SES credentials, Senda treats it as a new adapter.

So a new adapter gets its own tracking resources.

That is true when the second adapter lives in:

- the same workspace
- another workspace

## Why it works this way

The provisioning identity is derived from the adapter, not from the AWS account.

This keeps adapter setups isolated and makes the behavior easier to reason about.

## Subscription confirmation

After provisioning, AWS SNS sends a confirmation request to the Senda webhook endpoint.
Senda auto-confirms this request — no manual action is needed.

In rare cases, confirmation may take a few seconds after provisioning completes.
If the verify step shows as pending, it will resolve on its own once SNS delivers the confirmation.

### When confirmation might be delayed

- **AWS propagation delay**: SNS may take a moment to register the subscription as confirmed.
- **Cold start**: if the Senda server was scaled to zero, the first request may take longer.
- **Network**: transient connectivity between AWS and the hosting environment.

In all these cases, the confirmation will eventually succeed because the webhook endpoint is active and will auto-confirm.

### When to worry

If tracking events do not appear after several minutes:

1. Check that the adapter's AWS credentials still have SNS permissions.
2. Verify the webhook endpoint is reachable from the internet.
3. Try re-provisioning — Senda will skip already-completed steps and re-verify.

## What this means for you

If you are trying to reuse an existing SES setup:

- reuse the same adapter if that is the behavior you want
- create a new adapter if you want a separate tracking setup
