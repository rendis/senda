# Help Center

Welcome to the Senda Help Center.

Use this space to understand how the product behaves, where things live in the UI, and why certain flows work the way they do.

## Start here

- [Members](members) — invite people and manage access by scope.
- [API Keys](api-keys) — create and use workspace API keys.
- [SES tracking](ses-tracking) — understand what gets provisioned and what gets reused.
- [Send flow](send-flow) — see how Senda resolves templates, injectors, and adapters.
- [FAQ](faq) — quick answers to the most common questions.

## If you are looking for the API reference

Open the workspace API Docs page from the sidebar when you are inside a workspace.
That page shows the interactive OpenAPI reference for the data-plane APIs used by API key clients.

## What this help center is for

This help center is intentionally short and product-focused.

It is meant to answer:

- where to click
- what a screen does
- why a flow is scoped a certain way
- why some actions are visible only to certain roles
- what happens behind the scenes when Senda provisions providers

If you need a short answer, start with [FAQ](faq).
If you need the complete behavior of a feature, open the matching guide above.
