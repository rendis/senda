# HT-10: ChainResolver + InjectorMerger

**Épica:** E3 — Resolution Engine
**Spec:** §12.1 (ChainResolver), §12.2 (InjectorMerger)

## Objetivo

Implementar la resolución jerárquica workspace → _system → global y el merge de injectors campo por campo.

## Entregables

- `internal/resolution/chain.go` — `ChainResolver`
  - `Resolve(ctx, tenantCode, workspaceCode)` → `ResolvedChain{Workspace, SystemWorkspace, IsGlobal}`
  - Usa cache (port.Cache) con TTL 5min, key `chain:{tenantCode}:{workspaceCode}`
- `internal/resolution/injector_merger.go` — `InjectorMerger`
  - `Merge(ctx, workspaceID, injectorNames)` → `map[string]map[string]any`
  - Field-by-field merge: workspace values override _system, _system overrides global
  - Si un campo no tiene valor en ningún nivel y es required → error

## Criterios de Aceptación

- [x] ChainResolver retorna los 3 niveles correctos (workspace, _system, global)
- [x] Cache hit evita query a DB
- [x] InjectorMerger combina campos de 3 niveles correctamente
- [ ] Required fields sin valor producen error descriptivo — DEFERRED: `InjectorField` domain model no tiene campo `Required bool`. Se retorna nil para campos sin valor. Se implementara cuando el modelo lo soporte.
- [x] Tests unitarios con mock stores y mock cache

## Notas de Implementación

- API: `ChainResolver.Resolve(ctx, workspaceID)` toma UUID directamente (no codes). Cache key: `chain:<workspaceID>`.
- System workspace (IsSystem=true) produce chain de 2 scopes: `[ws, global]`. Regular workspace produce 3: `[ws, _system, global]`.
- `InjectorMerger.Resolve(ctx, workspaceID)` retorna `MergedInjectors` (`map[string]map[string]any`).
- Dedup de definitions por nombre: scope mas alto gana. Values se resuelven campo por campo con prioridad ws > _system > global.
- Helper `matchScope(*uuid.UUID, uuid.NullUUID)` para comparar scope types.
- Cache es best-effort: fallos de Set no bloquean el resultado.
- 14 unit tests (6 chain + 8 merger), todos pasan con `-race`.
