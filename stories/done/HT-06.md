# HT-06: Port Interfaces (Contratos)

**Épica:** E2 — Core Domain
**Spec:** §10 (Port Interfaces — 10.1 a 10.5)

## Objetivo

Definir todas las interfaces (ports) que conectan el domain con la infraestructura.

## Entregables

- `internal/port/email_sender.go` — `EmailSender` interface
- `internal/port/store.go` — Todas las store interfaces (TenantStore, WorkspaceStore, InjectorStore, TemplateTypeStore, TemplateStore, TemplateVersionStore, TemplateVersionLocaleStore, AdapterStore, DomainStore, MemberStore, MemberRoleStore, APIKeyStore, EmailStore, EmailEventStore, SuppressionStore, WebhookStore, AuditLogStore, GlobalConfigStore)
- `internal/port/queue.go` — `JobQueue` interface
- `internal/port/template_compiler.go` — `TemplateCompiler` interface
- `internal/port/cache.go` — `Cache` interface
- Tipos auxiliares: `ListOptions`, `PageResult[T]`

## Criterios de Aceptación

- [ ] Todas las interfaces de §10 definidas
- [ ] Cada método tiene context.Context como primer parámetro
- [ ] PageResult es genérico (`PageResult[T any]`)
- [ ] ListOptions soporta cursor + limit
- [ ] Compila sin errores (interfaces bien tipadas contra domain models)
