# HT-02: Configuration + Secrets Management

**Épica:** E1 — Foundation
**Spec:** §17 (Configuration)

## Objetivo

Implementar carga de configuración desde YAML + env vars, con validación y defaults.

## Entregables

- `config/config.go` — struct `Config` con sub-configs: `ServerConfig`, `DatabaseConfig`, `OIDCConfig`, `CryptoConfig`, `LogConfig`
- Parsing YAML + override por env vars (`SENDA_` prefix)
- `config/config.example.yaml` con todos los valores documentados
- Validación: campos requeridos, formatos de URL, master key length

## Criterios de Aceptación

- [x] Config se carga desde YAML, env vars override funcionan
- [x] Errores claros si falta configuración requerida
- [x] `config.example.yaml` incluye todos los campos con comentarios
- [x] Tests unitarios para parsing, defaults, y validación

## Notas de Implementación

- Used `go.yaml.in/yaml/v4` (v4.0.0-rc.4) instead of deprecated v3
- Env var overrides via reflection on `env` struct tags
- Defaults via reflection on `default` struct tags (two-pass: detects presence to handle explicit false/0)
- Priority: env vars > YAML > defaults
- Master key validation: >= 32 chars
- 12 unit tests covering all acceptance criteria
