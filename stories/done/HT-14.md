# HT-14: MJML Compiler + DKIM Signer

**Épica:** E4 — Send Flow
**Spec:** §22 (DKIM Signing), §10.4 (TemplateCompiler port)

## Objetivo

Implementar compilación MJML → HTML y firma DKIM de emails.

## Entregables

- `internal/adapter/mjml/compiler.go` — `MJMLCompiler` implementando `port.TemplateCompiler`
  - Usa gomjml (Go nativo) para convertir MJML → HTML responsive
- `internal/adapter/dkim/signer.go` — `DKIMSigner`
  - `GenerateKeyPair()` → (privateKey, publicKey, error) — RSA-2048
  - `Sign(message, domain, selector, privateKey)` → signed message
  - Usa go-msgauth para firma DKIM
- `internal/adapter/dkim/dns.go` — helpers para generar DNS records

## Criterios de Aceptación

- [x] MJML válido se compila a HTML responsive
- [x] MJML inválido produce error descriptivo (no panic)
- [x] DKIM sign + verify round-trip funciona
- [x] DNS records generados son correctos para la config
- [x] Tests unitarios con fixtures MJML

## Notas de Implementación

- MJML: gomjml (preslavrachev/gomjml v0.10.0) — pure Go, no WASM
- DKIM: go-msgauth (emersion/go-msgauth v0.7.0)
- Sign function is standalone (takes privateKeyPEM param), no store deps — full Signer struct deferred to HT-15
- PKCS8 format for private keys (more standard than PKCS1)
- Sign+verify round-trip test uses custom LookupTXT (no real DNS needed)
- TemplateCompiler port interface in internal/port/template_compiler.go
- 13 tests total (9 DKIM + 4 MJML)
