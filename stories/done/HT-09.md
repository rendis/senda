# HT-09: PostgreSQL Stores — Members, API Keys, Emails, Audit, Suppression, Webhooks

**Épica:** E2 — Core Domain
**Spec:** §10.2, §3.9–3.14

## Objetivo

Implementar las stores restantes para auth, tracking, y operaciones.

## Entregables

- `internal/adapter/postgres/member_repo.go` — MemberStore + MemberRoleStore
- `internal/adapter/postgres/apikey_repo.go` — APIKeyStore (hash lookup, revoke)
- `internal/adapter/postgres/email_repo.go` — EmailStore (insert, update status, query con pagination)
- `internal/adapter/postgres/suppression_repo.go` — SuppressionStore (check global + workspace, add, remove)
- `internal/adapter/postgres/audit_repo.go` — AuditLogStore (append-only)
- `internal/adapter/postgres/webhook_repo.go` — WebhookStore
- `internal/adapter/postgres/email_event_repo.go` — EmailEventStore

## Criterios de Aceptación

- [x] Member roles respetan CHECK constraint (scope_type vs role)
- [x] API key lookup por hash funciona en < 5ms
- [x] Email insert incluye todas las columnas de §3.11
- [x] Suppression check consulta global + workspace en una sola transacción
- [x] Audit log es append-only (no update, no delete)
- [x] Tests de integración con TestContainers

## Notas de Implementación

- Domain model refactored: Member (Name→DisplayName), MemberRole (+CreatedBy), Email (ProviderMsgID→ProviderMessageID), EmailEvent (+CreatedAt), AuditLog (removed IPAddress, use SQL aliases for ActorID/ActorEmail/EntityType/EntityID)
- Composite time cursor (EncodeTimeCursor/DecodeTimeCursor) for partitioned tables (emails, audit_logs) — 24-byte base64 encoding of (created_at nanoseconds + uuid)
- NormalizeLimit helper for repos with manual cursor handling
- IsSuppressed combines global+workspace check in single UNION ALL query
- APIKey ListByWorkspace excludes key_hash from SELECT for security
- AuditRepo: append-only (Insert only, no Update/Delete methods)
- Email CC/BCC: pgx v5 handles []string ↔ JSONB natively
- 64 integration tests total (17 member, 10 apikey, 11 email, 10 suppression, 6 audit, 10 webhook)
