# HT-01: Project Scaffolding + Docker Compose

**Épica:** E1 — Foundation
**Spec:** §9 (Estructura de Carpetas), §18 (Docker Compose)

## Objetivo

Crear la estructura de carpetas del proyecto Go, configurar el módulo, Docker Compose con PostgreSQL 16 + pg_cron, y Makefile base.

## Entregables

- `go.mod` inicializado con módulo `github.com/senda-app/senda`
- Estructura de carpetas: `cmd/senda/`, `internal/{domain,port,service,resolution,adapter,http}/`, `migrations/`, `config/`, `pkg/`, `docker/`
- `docker-compose.yml` con postgres:16-alpine + pg_cron (`shared_preload_libraries`), caddy (profile https)
- `Dockerfile` (multi-stage: build + alpine runtime)
- `Dockerfile.dev` (con hot reload via air o similar)
- `Makefile` con targets: `dev`, `build`, `test`, `migrate-up`, `migrate-down`, `lint`
- `.gitignore`, `.editorconfig`

## Criterios de Aceptación

- [x] `make dev` levanta el stack completo (senda + postgres) con docker compose
- [x] PostgreSQL acepta conexiones y pg_cron está habilitado (`SELECT * FROM cron.job` no falla)
- [x] `make build` genera el binario
- [x] `make test` ejecuta tests (aunque aún no haya ninguno)

## Notas de Implementación

### Decisiones

1. **postgres:16-bookworm en vez de alpine**: pg_cron no está empaquetado para Alpine + PG16. Se usa Debian bookworm con `postgresql-16-cron` vía apt. Custom Dockerfile en `docker/postgres/Dockerfile`.

2. **Puertos configurables**: Los puertos del host son configurables vía env vars (`SENDA_PORT`, `SENDA_PG_PORT`) para evitar conflictos. Defaults: 8081 (app), 5435 (pg).

3. **Volume mount comentado**: El volume mount `../:/app` para hot reload requiere que Docker Desktop tenga configurado file sharing para el path del proyecto. Se deja comentado con instrucciones. El `Dockerfile.dev` hace `COPY . .` como fallback.

4. **Echo v5 (v5.0.4)**: API confirmada via context7. Handler signature: `func(c *echo.Context) error`. Server startup: `echo.StartConfig{}.Start(ctx, e)`.

5. **Go 1.25**: Última versión estable, todas las dependencias en latest.

6. **Air v1.64.5**: Hot reload para desarrollo. Config en `.air.toml`.
