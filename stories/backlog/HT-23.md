# HT-23: Provider Event Ingestion (SES Webhooks)

**Épica:** E6 — Operations
**Spec:** §19 (Provider Event Ingestion — 19.1 a 19.5)

## Objetivo

Recibir eventos de providers (SES bounces, complaints, deliveries) y procesarlos.

## Entregables

- `internal/http/handler/provider_webhook.go` — SNS message parsing + signature verification
- `internal/service/event_processor.go` — `EventProcessor`
  - Update email status, side effects (suppression, timestamps), webhook dispatch

## Criterios de Aceptación

- [ ] SNS SubscriptionConfirmation auto-confirmed
- [ ] SNS signature verification blocks invalid payloads
- [ ] SES bounce → email status updated + suppression entry
- [ ] SES complaint → workspace suppression entry
- [ ] SES delivery → email delivered_at updated
- [ ] SES open → email opened_at updated
- [ ] Events dispatched to active webhooks
- [ ] Unknown events logged but not processed
- [ ] Tests con SNS payload fixtures
