# HT-27: API Keys Service + Management Endpoints

**Épica:** E6 — Operations
**Spec:** §3.10 (Schema), §10.2 (APIKeyStore), §15.3 (Routes)

## Objetivo

Implementar generación, validación, y gestión de API keys.

## Entregables

- `internal/service/apikey.go` — `APIKeyService`
  - Generate: `senda_live_` + 32 random hex, SHA-256 hash, last 8 chars hint
  - Validate, Revoke, ListByWorkspace
- `internal/http/handler/apikey.go` — POST/GET/DELETE endpoints

## Criterios de Aceptación

- [ ] Generate retorna key completa solo una vez
- [ ] Key hash lookup funciona para auth
- [ ] Revoked key rechaza auth
- [ ] List no expone key ni hash (solo hint)
- [ ] Tests: generate → validate → revoke → validate fails
