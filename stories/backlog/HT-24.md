# HT-24: Webhook System (Dispatch + CRUD)

**Épica:** E6 — Operations
**Spec:** §16.3–16.4 (WebhookWorker + WebhookService), §15.3 (Routes)

## Objetivo

Implementar el sistema de webhooks para notificar a consumidores sobre eventos de email.

## Entregables

- `internal/http/handler/webhook.go` — CRUD webhooks (auto-generate secret, test endpoint)
- `internal/service/webhook.go` — `WebhookService` (dispatch, filter by event type)

## Criterios de Aceptación

- [ ] CRUD webhooks funciona
- [ ] Secret auto-generated en create (no en response de list)
- [ ] Dispatch enqueue un job por cada webhook activo suscrito
- [ ] WebhookWorker entrega con firma HMAC verificable
- [ ] Test webhook endpoint envía ping y reporta resultado
- [ ] Tests de integración
